# Getting started with solana-wallet-toolkit

[](https://www.rust-lang.org/) [](https://www.typescriptlang.org/) [](https://solana.com/)

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/solana-wallet-toolkit.git
cd solana-wallet-toolkit
```
